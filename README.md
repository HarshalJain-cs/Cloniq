## <img src="https://media.giphy.com/media/iY8CRBdQXODJSCERIr/giphy.gif" width="30"> What Is Cloniq?

> **Your expertise. Working 24/7. Earning while you sleep.**

**Cloniq is the world's first agentic marketplace** — where anyone can turn their knowledge into an AI agent, deploy it instantly, and monetize it across every channel. Web, WhatsApp, Claude Desktop, ChatGPT, REST API — your agent lives everywhere.

```
You upload your notes  →  AI agent goes live  →  Anyone queries it  →  You earn USDC
```

Think of it as:

| Analogy | How Cloniq Differs |
|:--------|:-------------------|
| **Fiverr** | But your AI does the work, not you |
| **Substack** | Readers pay per answer, not per month |
| **API Marketplace** | APIs built from human expertise, not code |

<td width="50%">

### 🏗️ How We Built This

We followed a **monorepo-first, full-stack** approach:

1. **Scaffolded** a Turborepo monorepo with three packages — `web`, `mcp-server`, and `contracts`
2. **Built the RAG engine first** — pgvector embeddings, semantic search, streaming responses
3. **Deployed smart contracts** on Base Sepolia for on-chain agent identity
4. **Added multi-channel access** — Web UI, WhatsApp (Twilio), MCP (Claude/Cursor), ChatGPT Actions
5. **Layered payments** — x402 USDC micropayments + Razorpay fiat onramp for Indian users
6. **Built agentic workflows** — DeFi yield aggregator, options trading, 3D designer, UI/UX designer
7. **Added business platform** — Automaton AI integration with conversational AI, voice meetings, omnichannel services
8. **Polish & UX** — Lenis smooth scroll, Framer Motion animations, premium glassmorphism design

</td>
<td width="50%">

### 🎯 Design Principles

- **Zero Friction** — Google login, no wallet setup, no seed phrases
- **Creator First** — Deploy agents in < 2 minutes, earn from day one
- **Multi-Channel** — Same agent, accessible from Web, WhatsApp, MCP, API
- **Bleeding Edge** — Next.js 15, React 19, Tailwind v4, Groq inference
- **On-Chain Identity** — Every agent registered on Base Sepolia
- **Pay-Per-Query** — Micropayments starting at $0.01/query in USDC
- **RAG-Powered** — Every response grounded in the creator's knowledge base
- **Sub-2s Responses** — Groq's llama-3.3-70b with streaming SSE

## 🏛️ Architecture

```
┌─────────────────────────────────────────────────────────────────────────┐
│                          REQUEST FLOW                                   │
└─────────────────────────────────────────────────────────────────────────┘

  User (Web / WhatsApp / MCP / ChatGPT / REST API)
        │
        ▼
  ┌─────────────┐     API Key (sk-cloniq-...)
  │  Auth Gate  │  ─────────────────────────── MCP / Programmatic
  │             │     x402 USDC payment         Web queries
  └──────┬──────┘
         │
         ▼
  ┌──────────────────┐
  │   RAG Retrieval  │   HuggingFace all-MiniLM-L6-v2 (384-dim)
  │                  │   pgvector cosine similarity search
  │  agent's private │   returns top-k relevant chunks from
  │  knowledge base  │   the creator's uploaded documents
  └──────┬───────────┘
         │
         ▼
  ┌──────────────────┐
  │    Groq LLM      │   llama-3.3-70b-versatile
  │                  │   System prompt = agent personality
  │  context-aware   │   + retrieved knowledge chunks
  │  generation      │   + user question
  └──────┬───────────┘
         │
         ▼
  Streamed response (SSE) or JSON
  → Web UI  → WhatsApp  → MCP client  → ChatGPT  → REST
```

## 🚀 Quick Start

```bash
# Clone the repo
git clone https://github.com/vyqno/agentic-marketplace.git
cd agentic-marketplace

# Install dependencies
pnpm install

# Set up environment
cp .env.example apps/web/.env.local
# Fill in your API keys

# Run development server
cd apps/web && pnpm dev
```

### Required Environment Variables

```env
NEXT_PUBLIC_SUPABASE_URL          # Supabase project URL
SUPABASE_SERVICE_ROLE_KEY         # Supabase service key
GROQ_API_KEY                      # Groq API key (for LLM)
NEXT_PUBLIC_THIRDWEB_CLIENT_ID    # thirdweb auth
RAZORPAY_KEY_ID                   # Razorpay payments
RAZORPAY_KEY_SECRET               # Razorpay secret
PLATFORM_WALLET_ADDRESS           # x402 payment wallet
HF_TOKEN                          # HuggingFace (optional, for RAG)
```

## 📡 API Reference

```
# Agents
GET    /api/agents                    List agents (search, tag, owner filter)
POST   /api/agents                    Deploy a new agent
GET    /api/agents/:name              Get agent profile
POST   /api/agents/:name/ask          Query agent (x402 or API key)
POST   /api/agents/:name/ask/stream   Streaming SSE response
POST   /api/agents/:name/documents    Upload .md knowledge file
POST   /api/agents/:name/memory       Seed agent memory

# Users & Keys
GET    /api/user/me                   Current user via API key
POST   /api/keys                      Create API key → sk-cloniq-...
DELETE /api/keys                      Revoke key

# Payments
POST   /api/topup/create-order        Razorpay INR → USDC order
POST   /api/topup/verify              Verify + credit USDC

# Integrations
GET    /api/openapi                   OpenAPI 3.0 spec (ChatGPT Actions)
POST   /api/whatsapp                  Twilio webhook
GET    /api/x402/session-token        x402 payment config

# Agentic Workflows
POST   /api/agents/yield-aggregator   DeFi yield farming
POST   /api/agents/options-trader     Leveraged options trading
POST   /api/agents/3d-designer        3D scene generation
POST   /api/agents/ui-ux-designer     UI component generation
```

## 🗄️ Database Schema

```sql
agents              -- profiles, wallet, price, skill tags, query count
agent_memories      -- pgvector 384-dim embeddings of uploaded knowledge
users               -- wallet address, USDC credit balance
api_keys            -- sk-cloniq-... keys, usage tracking
topup_transactions  -- Razorpay order history (INR → USDC)
whatsapp_sessions   -- per-number conversation state

-- Custom RPCs
match_agent_memories(embedding, agent_id, k)   -- cosine similarity search
increment_query_count(agent_name)              -- atomic counter
deduct_usdc_credits(wallet, amount)            -- atomic credit deduction
```
